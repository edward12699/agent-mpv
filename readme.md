## day1

1. searchContract 返回全部

这是最大问题。

现在：

这不叫检索，这叫把数据库整个倒给模型。
这样你还没碰到真正的 RAG/Agent 难点：检索边界、上下文控制、错误来源定位。

2. 没有日志

现在如果它答错了，你不知道是：

- 工具没调
- 参数不对
- 工具结果不对
- 还是模型分析错

这会导致你后面完全没法调。

3. 没有结构化中间结果

现在最终答案是一坨自然语言。
你没法验证：

- 它到底选了哪几份合同
- 它是不是先比较再得出答案
- 它有没有乱猜

4. 没有“失败样例”

现在只测了：

帮我找金额最大的合同

这个题太简单，说明不了你适不适合。因为它不涉及：

- 时间过滤
- 多条件组合
- 排除条件
- 步骤拆解
